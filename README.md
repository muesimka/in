# Домашнее задание: Уроки 3-4. Типы данных и параметры. Нормализация до 3НФ

**Тема:** Типы данных и параметры. Нормализация базы данных до Третьей нормальной формы (3NF).

**Исходная таблица:** `StudentGrades` (журнал учёта результатов тестирования студентов).

## Структура репозитория

```
db-normalization-hw/
├── README.md                 # Этот файл
├── theory.md                 # Часть 1. Теоретический анализ
├── schema.md                 # Схема данных (ER) + описание таблиц
├── sql/
│   └── create_tables.sql     # SQL-скрипты CREATE TABLE (3NF)
└── data/
    └── sample_data.sql       # Пример INSERT для проверки
```

## Как использовать

1. Клонируйте репозиторий.
2. Выполните SQL-скрипт `sql/create_tables.sql` в вашей СУБД (MySQL / PostgreSQL / SQLite).
3. При желании загрузите тестовые данные из `data/sample_data.sql`.
